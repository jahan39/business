SWEET CRUMBS CAKE STORE — FRONTEND STARTER
============================================

Folders:
- HTML/ : all website pages
- CSS/  : style.css
- JS/   : app.js

How to open in VS Code:
1. Extract all three ZIP files into ONE project folder, keeping the HTML, CSS and JS folders together.
2. Open that project folder in VS Code.
3. Install the VS Code "Live Server" extension (recommended).
4. Right-click HTML/index.html -> Open with Live Server.
5. Do not open individual files from different extracted folders; keep the folder structure intact.
